\chapter{Discussion}
\label{ch:discussion}

Semantic entropy performs well against the
baselines in the original study, but grouping answers by meaning does not
consistently improve on counting normalized answer strings. The result depends
on the entailment model and on how correctness is judged.

\section{What grouping by meaning adds}
\label{sec:what-clustering-is-worth}

\subsection{Normalization gives the most consistent improvement}

The decomposition in Section~\ref{sec:ladder} separates counting strings,
normalizing them, grouping them by meaning, and weighting the resulting groups
by likelihood. Normalization gives the most consistent improvement across the
tested conditions. It merges simple differences in capitalization,
punctuation, articles, and spacing without using another language model.

Counting raw strings does not consistently improve on reading sequence
likelihoods. The improvement becomes consistent only after the strings are
normalized. Weighting meaning groups by likelihood changes the results very
little. These findings help explain why discrete semantic entropy performs
similarly to the likelihood-weighted version in this study.

The comparison with surface entropy is important because the original
baselines do not isolate grouping by meaning. Surface entropy also outperforms
those baselines in every comparison where each was measured. Their results
therefore do not show that semantic grouping causes the improvement.

This decomposition is not a perfect controlled comparison. Surface entropy
counts normalized answers, whereas the released semantic-clustering procedure
receives the raw answers. The comparison changes both the grouping rule and
the text supplied to it. That difference limits how precisely the observed
change can be attributed to semantic grouping alone.

\subsection{The released entailment models show no clear additional benefit}

With the default entailment model, \texttt{deberta-v2-xlarge-mnli}, none of
the confidence intervals for the difference between semantic and surface
entropy excludes zero under either LLM correctness judge. The other released
cross-encoder, \texttt{nli-deberta-v3-large}, gives the same overall pattern
under LLM grading.

This means the study did not detect an additional benefit. It does not mean
the methods are equivalent. The design has few independent
dataset--model units, and small improvements may remain undetected. Some
intervals are also much wider than others. A single claim that the study had
enough power for every condition would be misleading.

The statistical unit matters here. Resampling only question records gives
narrower intervals because it holds the chosen datasets and generating models
fixed. Resampling dataset--model units as well answers a broader question and
makes several apparent differences uncertain. More records or seeds within the
same units cannot replace testing on more datasets and generating models.

None of this means that semantic entropy fails as a detector. It means that,
with these entailment models and labels, the study does not show an
improvement over a simpler detector that counts normalized strings.

\subsection{Changing the entailment model changes the result}

The result changes when \texttt{Qwen2.5-72B-Instruct} judges entailment.
Semantic entropy then improves on surface entropy under both LLM correctness
judges, for both sentence-length and short-phrase answers. The stored answers
are identical across this comparison, and surface entropy does not change.
The improvement therefore comes from changing the entailment model within the
tested procedure.

This supports a narrower conclusion than saying that semantic grouping always
works or never works. Its measured value depends on the model used to decide
whether answers mean the same thing. That model must be named when
semantic-entropy results are reported.

\subsection{Answer length alone does not explain the pattern}

Longer answers allow more ways to express the same meaning, but length alone
does not explain the results. Changing the entailment model reverses which
generator gains most from semantic grouping, even though its answers stay
fixed. The generator with the longest answers gains least with the default
entailment model and most with the Qwen entailment model.

The prompting-factorial analysis offers a limited additional check. It varies
instruction wording and the number of worked examples, but it was run only
with the default entailment model. Its four semantic-versus-surface intervals all
include zero. It is therefore a secondary analysis, not evidence
that answer length causes the observed differences. The full results are in
Appendix~\ref{sec:factorial-results}.

The biography experiment is exploratory. Its string-based estimators perform
near chance, its exact entity list cannot be
recovered from the stored repository, and its clustering rule differs from the
original paragraph experiment. No general claim about long-form detection follows
from it. Appendix~\ref{sec:longform-results} reports its findings
and limitations.

\section{Why the evaluation setup matters}
\label{sec:apparatus}

The entailment model, sampling temperature, and correctness rule can change
both the size and the direction of a method comparison. The entailment and
grading checks reuse the same stored answers. The temperature experiment
instead changes the uncertainty samples while keeping the graded answer and
its LLM correctness label fixed. These are different kinds of checks and
should not be described as changes made to one fixed generation set.

\subsection{The entailment model is part of the method}

The tested entailment models produce different AUROC values and disagree about
how many meaning groups an answer set contains. Describing all of them as
bidirectional entailment clustering is not enough to make the measurement
reproducible. The model, prompt, and clustering rule are part of the method,
not minor implementation details.

\subsection{Sampling temperature changes which detector leads}
\label{sec:diversity-vs-likelihood}

At lower temperatures, the sampled answers become less varied. The detectors
that measure variation across samples lose more accuracy than the detector
based on sequence likelihoods. The order of the methods changes across the
tested range. An advantage measured at one temperature should therefore not be
assumed to hold at another.

The highest temperature tested here is the most favorable tested setting for
the sample-based detectors. It does not follow that this is a general optimum.

\subsection{The correctness rule can reverse the comparison}

Identical answers and detector scores can produce a different method ranking
when the correctness labels change. In the sentence-length condition, surface
entropy leads under token-F1, while semantic entropy has higher point estimates
under the LLM judges. With the default entailment model, however, the
LLM-graded intervals include zero.

Token-F1 can penalize a correct but long answer because it compares that answer
with a short reference. In some tested groups it labels very few answers
correct, making AUROC estimates unstable. The LLM judges avoid simple
token-overlap matching, but their labels are not ground truth
either. There are no human annotations in this study to determine which rule
better reflects actual correctness.

\subsection{The metric comparison is secondary}

The rejection-accuracy summaries can rank methods differently from AUROC.
They also track the generating model's accuracy more closely. This makes them
useful for describing the answers retained after rejection, but less suitable
as the main comparison of detector ranking quality in this thesis. AUROC
remains the primary metric. The complete secondary analysis is in
Appendix~\ref{sec:aurac-disagreement}.

\section{What reproduces from the original studies}
\label{sec:comparison-farquhar}

Semantic entropy performs better than the measured original baselines, and its
discrete and likelihood-weighted forms perform similarly. The probe results
also show lower accuracy on held-out datasets. These findings support key
patterns reported by Farquhar et al.~\cite{semantic_entropy_nature_2024} and
Kossen et al.~\cite{kossen_semantic_entropy_probes_2024}.

The comparison is limited to the configurations tested here. P(True) does not
show the original model-size trend within the tested Llama models, but a
comparison within one family is not enough to reject a broader trend. The
semantic-entropy comparator uses different entailment models in its comparisons
with P(True) and the probes. The out-of-distribution probe conditions also use
different graders and must each be compared with their matching
in-distribution result.

This is a reimplementation of the released procedure, not an exact repeat of
the original experiment. The datasets, generating models, correctness judges,
and answer lengths differ. The generation settings also allow the answer being
graded to be longer than the samples used to estimate uncertainty. Following
the released code makes those choices traceable, but does not remove their
effect on the results.

The main addition is the normalized-string comparator. It shows that the
original baseline comparisons alone do not identify the value of semantic
grouping. The added entailment-model comparison then shows when an additional
benefit can be detected in this study.

\section{Threats to validity}
\label{sec:threats}

The following limits remain part of the main argument because they affect how
the results can be interpreted.

\paragraph{No human correctness labels.}
All correctness labels come from token overlap or an LLM judge. Agreement
between the LLM judges measures their consistency with each other, not their
accuracy against human judgment. They could agree and still make the same
mistakes. Every reported accuracy and detector-performance estimate depends on these
unvalidated labels.

\paragraph{Dependence between semantic grouping and grading.}
The entailment model compares meanings, and the LLM correctness judges also
compare an answer with a reference by meaning. Shared preferences or errors
could favor semantic entropy without reflecting better detection of incorrect
answers. Re-grading with a different model leaves the main entailment-model
ranking largely unchanged, which reduces concern about using one particular
model in both roles. It does not rule out shared errors across models or
validate the labels against people.

\paragraph{Few independent statistical units.}
Seeds are repeated runs within dataset--model units, not independent tests of
generalization. The hierarchical analysis accounts for variation between the
units, but the limited set of datasets and generators still restricts the
conclusions. A confidence interval that includes zero does not rule out a
small benefit.

\paragraph{Different answer lengths and generation limits.}
The sentence-length condition produces longer answers than the original study.
The samples used for uncertainty and the answer judged for correctness also
have different token limits. This limits direct comparison with the published
result.

\paragraph{Order-dependent clustering.}
The released algorithm processes answers in generation order, and changing
that order can change the final groups without changing the entailment
judgments. Appendix~\ref{sec:order_dependence_example} gives a worked example.
The entailment-model comparison does not measure or bound this ordering effect.

\paragraph{Incomplete experimental coverage.}
Not every detector, prompting condition, temperature, and entailment model was
tested together. The prompting-factorial and metric analyses are secondary.
The exploratory biography experiment has incomplete provenance, one grader,
and a different paragraph-clustering rule. These limits prevent it from
supporting a central claim about long-form detection.

Taken together, the results support a conditional finding: semantic entropy
can improve on normalized-string counting with the tested Qwen entailment
model, but no such improvement was detected for the released
cross-encoders under LLM grading. Human labels and broader dataset--model
coverage are needed before making a stronger claim.
